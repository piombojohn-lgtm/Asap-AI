A native Windows AI coding workspace from **Asap Studio**.

The installer is approximately 180 MB. This repository hosts public downloads and setup information.

## Get started

1. Download and run the Windows installer.
2. Open **Asap Ai** from the Start menu. Project and editor tools are available immediately.
3. For local AI, open **Help → Set up local AI**, install [Ollama for Windows](https://ollama.com/download/windows), and choose to download and prepare the Asap model.
4. Refresh the model list and start a chat.

The separate local model download is approximately 13 GB. Allow at least 20 GB of free disk space; 16 GB or more RAM is recommended. Performance depends on your hardware. Model details and license: [gpt-oss:20b](https://ollama.com/library/gpt-oss:20b).

## Workspace features

- Native Windows desktop editor, file tabs, project navigation and search.
- AI chat with Ask, Plan and Code modes, local model choices and optional online providers.
- Reviewed file changes, recovery checkpoints, and protection against stale saves.
- Conversation history and local memory controls.
- Optional read-only plugins and the original terminal interface.

## Requirements and privacy

- Windows 10/11, x64. App helper runtimes are included.
- Ollama/model weights, Git and project language SDKs are separate installations.
- Optional online providers require your own tools, accounts and any applicable subscriptions or credits.
- Plugins start disabled; automatic memory starts off. No developer accounts, credentials, chats or model weights are included.
- Personal data is stored in `%LOCALAPPDATA%\AsapAi`. Uninstall preserves this data and your projects.
